# DocMind
This Project helps to identify the information available as PDF or any text forms and deliver required details to users, without waiting to customer care or searching on where is the detail. This saves time for customer and also there is a upgrade to this version to make this work by creating ticket in customer end where they raise any issue.

This ticketing will help to track on progress of each issue and resolve it on time.

1)  The input should be given to this model and it maintains versions of it, like if its fed with info_1 then later updated same file to info_2 -> it will get latest info and deliver that.(so need to have access to files and whaever uploaded inside certain repo it should be accessible and version controllable).

2)  if user face any issue or needs clarification they can create ticket, labelled respectively whether its clarification apart from which is not available in bot/ inaccurate in bot.

3)  the ticket should route to respective team and that team resolve it asap
